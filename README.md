## 📘 Project Description
This project is part of the **HNG13 Stage 0 DevOps** challenge.  
The goal is to set up and deploy a simple web server using **NGINX**, hosted on a cloud provider or any publicly accessible machine.

The deployment should serve a custom `index.html` page at the root path (`/var/www/html/index.html`), running on **port 80** and accessible publicly.
